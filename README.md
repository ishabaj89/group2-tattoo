The deadline for the project is October 1st. At this time you will present the project by doing a screen share, showing your final project, talking about the process of creating the project, what went well, and what you have learned for next time. 
When working in groups, we need to all contribute to the same repository on GitHub. One person in the team will need to create a repository with the basic project structure. Everyone else in the team will need to share their GitHub user name. The person who created the repository will then go into the 'settings' tab, choose 'collaborator' on the left side menu, and add all group members as contributors. Everyone then needs to go into their email account connected to GitHub and accept the invitation to collaborate. 
Each person should work in their own branch. This is to help reduce the amount of merge conflicts you will have in your code. Once your code is done, make sure you merge it to the master (or main) branch. All code for the final project should be located on this branch. 
To make working with Git and GitHub a bit easier, I suggest using a program such as GitHub Desktop (this is the program I personally use) or Git Kraken. This will help streamline the process and reduce errors due to user mistakes. 
 
I recommend that you start by setting up a group meeting to decide how you will work on this project, internal deadlines, individual responsibilities, and project standards. Remember to use the Agile Method to help streamline the project process.
